# v1.0.13 迁移说明

v1.0.13 为生成项目增加项目拥有的主题覆写配置，并加入 Prettier 格式化规则。

## 新项目

使用以下命令创建项目，会得到包含 `src/config/theme.ts` 的 Expo SDK 57 项目：

```bash
npx --yes --package "git+ssh://git@gitee.com/yu-guangji/rn-expo-template-kit.git#v1.0.13" create-rn-expo-app my-app --app-id com.company.myapp
```

在 `src/config/theme.ts` 中按 light/dark 设置需替换的色令牌；未设置的令牌保留模板默认值：

```ts
import { type ThemeOverrides } from "rn-expo-template-kit";

export const themes = {
  light: { primary: "#22386A" },
  dark: { primary: "#FFF6E5" },
} satisfies ThemeOverrides;
```

`ThemeProvider` 会由生成项目的 `AppThemeProvider` 自动接收这些覆写。需要读取当前主题名称时，可使用 `useThemeName`；需要已合并的色令牌时，继续使用 `useTheme`。

## 已有项目

先升级模板：

```bash
npm run template:update -- v1.0.13
```

如需自定义颜色，在项目新增 `src/config/theme.ts`，并在
`src/providers/app-theme-provider.tsx` 将 `themes` 传给 `ThemeProvider`。已有项目不配置
覆写时，主题行为与此前一致。

项目根目录新增 `.prettierrc.json`。如项目已有自己的 Prettier 规则，应先合并必要配置，
再执行格式化，避免无关格式改动。

## 验证

```bash
npm run template:doctor
npm run typecheck
npm run lint
```
