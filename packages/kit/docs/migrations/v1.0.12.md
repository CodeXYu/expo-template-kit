# v1.0.12 迁移说明

v1.0.12 为新建项目加入 `react-native-keyboard-controller`。新项目仍默认使用 Expo SDK 57；
生成器通过 Expo CLI 解析与所选 SDK 兼容的原生依赖版本。

## 新项目

使用默认命令创建项目即可获得 Expo SDK 57 与兼容的键盘库版本：

```bash
npx --yes --package "git+ssh://git@gitee.com/yu-guangji/rn-expo-template-kit.git#v1.0.12" create-rn-expo-app my-app --app-id com.company.myapp
```

## 已有项目

`template:update` 不会升级业务项目已经声明的直接依赖。先升级模板，再显式升级键盘库：

```bash
npm run template:update -- v1.0.12
npx expo install react-native-keyboard-controller
```

该库包含原生模块；完成依赖升级后，重新构建 iOS 和 Android 开发/发布构建。
