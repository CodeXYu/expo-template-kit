# v1.0.11 迁移说明

v1.0.11 扩展新建项目的 SDK 选择：默认使用支持列表中的最新 Expo SDK 57，
也支持通过 `--sdk 54`、`--sdk 56` 或 `--sdk 57` 手动选择版本。React Native 版本由对应
的 Expo SDK 模板自动决定。

## 使用方式

```bash
create-rn-expo-app my-app --app-id com.company.myapp --sdk 54
```

已有项目无需修改业务源码；升级共享包时使用精确 tag：

```bash
npm run template:update -- v1.0.11
```

## 验证

```bash
npm run typecheck
npm run lint
npm test
```
