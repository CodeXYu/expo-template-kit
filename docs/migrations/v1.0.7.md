# v1.0.7 迁移说明

v1.0.7 修复 Reactotron socket 连接完成前页面首屏日志丢失的问题，并保留 warn/error
级别。新生成项目已包含修复；`template:update` 不会覆盖项目拥有的
`src/config/reactotron.native.ts`，已有项目需要手动采用本版本模板中的对应文件。

## 更新依赖

```bash
npm run template:doctor
npm run template:update -- v1.0.7
```

## 更新 Reactotron 配置

将 v1.0.7 的 `template/src/config/reactotron.native.ts` 与项目中的
`src/config/reactotron.native.ts` 对比合并。关键行为如下：

- 调用 `.useReactNative({ log: false, ... })`，避免内置插件在连接后再次包装 console。
- `.connect()` 后立即桥接 `console.log/info/warn/error/debug`。
- 连接前日志由 Reactotron client 队列保存。
- warn/error/debug 分别使用 `client.warn`、`client.error`、`client.debug`；log/info 使用
  `client.log`。

Development 的 `.env.development` 应保留空 host，让 Reactotron 从 Metro bundle 地址
推导电脑地址：

```env
EXPO_PUBLIC_REACTOTRON_HOST=
```

INT 真机仍需在具体项目环境中填写可访问的电脑局域网 IP，不要把个人 IP 提交到通用模板。

## 验证

```bash
npm run typecheck
npm run lint
```

随后冷启动应用并确认：

1. `src/app/_layout.tsx` 和 `src/pages/home/index.tsx` 的首屏日志都能在 Reactotron 展示。
2. `console.log/info/warn/error/debug` 与 logger 对应方法各出现一次，没有重复。
3. warn 和 error 在 Reactotron 中保留正确级别。
