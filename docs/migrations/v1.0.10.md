# v1.0.10 迁移说明

v1.0.10 增强生成项目的应用基础设施：根层统一维护网络状态和应用生命周期，首页会在明确
离线时显示提示；启动、路由和未找到页面增加可重试的错误界面，`BasePage` 默认接入键盘
避让能力。

## 更新依赖

```bash
npm run template:doctor
npm run template:update -- v1.0.10
```

已有项目升级后，请重新安装依赖并重新构建原生项目，使
`react-native-keyboard-controller` 生效：

```bash
npm install
npx expo prebuild
npx expo run:android
npx expo run:ios
```

## 网络状态与页面状态

生成项目根层只挂载一个 `NetworkStatusProvider`。页面通过 `useNetworkStatus` 读取
`isOffline`，不要在页面重复订阅 `expo-network`。`BasePage` 不会因为设备断网自动切换状态；
请求失败且没有可展示内容时，由页面逻辑显式传入 `pageStatus="offline"`，以保留已有内容并
避免网络状态闪烁。

## 错误恢复与键盘处理

- 根布局会显示启动失败、路由失败和未找到页面的本地化错误界面，并提供重试或返回首页操作。
- `AppProviders` 已挂载 `AppLifecycleProvider` 和 `KeyboardProvider`；包含输入框的页面可
  直接使用 `BasePage` 默认键盘避让。需要自行控制布局时，传入 `keyboardAware={false}`。

## 验证

```bash
npm run typecheck

npm run verify:boundaries
npm run verify:matrix
npm run pack:check
```
