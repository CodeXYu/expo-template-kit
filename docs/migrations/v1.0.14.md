# v1.0.14 迁移说明

v1.0.14 修复 `react-native-keyboard-controller` 在业务项目与
`rn-expo-template-kit` 之间重复安装的问题。共享包改为声明 peer dependency；新建项目由
Expo CLI 根据所选 SDK 安装兼容的原生模块版本。

## 新项目

使用默认命令创建项目即可获得与 Expo SDK 57 兼容的键盘库版本：

```bash
npx --yes --package "git+ssh://git@gitee.com/yu-guangji/rn-expo-template-kit.git#v1.0.14" create-rn-expo-app my-app --app-id com.company.myapp
```

## 已有项目

先升级模板，再让 Expo 修正键盘库版本：

```bash
npm run template:update -- v1.0.14
npx expo install react-native-keyboard-controller
npx expo-doctor
```

如果此前升级到 v1.0.13 后仍看到重复依赖，请在 `package.json` 添加以下临时覆盖，然后重新安装：

```json
{
  "overrides": {
    "react-native-keyboard-controller": "1.21.9"
  }
}
```

```bash
npm install
npx expo-doctor
```

该库包含原生模块；依赖变更后，重新构建 iOS 和 Android 开发/发布构建。
